# Fundamentos de Python

Este repositório reúne exercícios desenvolvidos durante meus primeiros estudos de programação com Python.

Os códigos foram criados para praticar lógica de programação, estruturas condicionais, laços de repetição, listas, funções e operações matemáticas.

## Exercícios desenvolvidos

- **Calculadora básica:** operações de soma, subtração, multiplicação, divisão e resto da divisão.
- **Verificador de números primos:** utilização de funções e estruturas de repetição.
- **Cadastro de alunos:** armazenamento de nomes e notas em listas, com cálculo da média da turma.
- **Outros exercícios:** resolução de problemas matemáticos, estruturas de controle e atividades introdutórias de programação.

## Tecnologias utilizadas

- Python 3

## Objetivo

Registrar minha evolução no aprendizado de Python, aprimorando meu raciocínio lógico e minha capacidade de resolver problemas por meio da programação.

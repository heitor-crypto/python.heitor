**Fundamentos de Python**

Este repositório reúne exercícios desenvolvidos durante meus estudos iniciais de programação com Python, com foco em lógica de programação, resolução de problemas e construção de uma base sólida na linguagem.

**Conteúdos praticados**

- Variáveis, tipos de dados e operadores aritméticos
- Estruturas condicionais (if, elif e else)
- Laços de repetição (for e while)
- Listas e manipulação de dados
- Funções e organização de código
- Entrada de dados e tratamento básico de erros

**Exercícios desenvolvidos**

| Exercício | Descrição |
|---|---|
| Calculadora básica | Operações matemáticas com menu interativo e validação de entradas |
| Verificador de números primos | Identificação de números primos utilizando lógica matemática |
| Cadastro de alunos | Armazenamento de nomes e notas, com cálculo de médias |
| Equação do segundo grau | Cálculo das raízes utilizando a fórmula de Bhaskara |
| Calculadora de IMC | Cálculo e classificação do Índice de Massa Corporal |
| Conversor de temperaturas | Conversões entre diferentes escalas de temperatura |
| Tabuada | Geração de tabuadas utilizando estruturas de repetição |
| Outros exercícios | Problemas envolvendo listas, médias, condicionais e operações matemáticas |

**Tecnologias utilizadas**

- Python 3
- Git e GitHub para versionamento e organização dos exercícios

**Objetivo**

Documentar minha evolução no aprendizado de Python, aprimorando meu raciocínio lógico e minha capacidade de desenvolver soluções por meio da programação.

Este repositório representa minha trajetória de aprendizado e será atualizado conforme eu adquirir novos conhecimentos.
